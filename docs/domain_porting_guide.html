Read First: Critical Pitfalls Found on Live hems-workshop.org DNS & Registry

Must Review Before Starting
1. Switch Nameservers to Google Cloud DNS BEFORE Submitting EPP Transfer Code! Once you submit an EPP transfer code to a new registrar, the .org registry puts the domain into pendingTransfer. ICANN freezes ALL nameserver edits while a transfer is pending! Always pre-load Google Cloud DNS and switch GoDaddy Nameservers to ns-cloud-*.googledomains.com first, then unlock & transfer 10 minutes later.
2. Google Cloud DNS Requires a Trailing Dot (.) on Hostnames In Google Cloud DNS, MX and CNAME targets MUST end with a period: 1 smtp.google.com. and hems-workshop.web.app.. If you omit the trailing dot, Cloud DNS appends your domain (smtp.google.com.hems-workshop.org), which breaks email!
3. Google Cloud DNS Groups All Root @ TXT Values Into ONE Record Unlike GoDaddy (which uses 3 separate rows), Cloud DNS uses strict RFC record sets: create one single TXT record at the root (hems-workshop.org.) and click "+ Add item" 3 times to hold: (1) google-site-verification=..., (2) hosting-site=hems-workshop, and (3) v=spf1 include:_spf.google.com ~all.
4. Do NOT Edit GoDaddy Contact / WHOIS Info (60-Day Lock Trap!) If you change the Registrant Name, Organization, or Email inside GoDaddy right before leaving, GoDaddy triggers an automatic 60-day ICANN Change-of-Registrant transfer lock! Leave contact info as-is while transferring out (update it at your new registrar after transfer completes).
5. Sucuri / GoDaddy Website Security WAF IP (192.124.249.10) Your live @ A record points to 192.124.249.10—GoDaddy's Website Security Firewall (Sucuri WAF) proxy. Disable/cancel GoDaddy Website Security WAF and ensure GoDaddy's Forwarding panel is Off so nothing interferes with Let's Encrypt SSL or keeps billing your card.
6. Canonical Direction: www MUST Be Primary (Not Apex) Every <link rel="canonical">, sitemap.xml URL, JSON-LD citation, and llms.txt link uses https://www.hems-workshop.org/. In Firebase Hosting, add www.hems-workshop.org FIRST as Primary, and add hems-workshop.org SECOND as a Redirect to www.hems-workshop.org.
7. Select "Keep Existing Nameservers" During Registrar Transfer When pasting your EPP code into Squarespace Domains or Porkbun, make sure Keep existing nameservers (ns-cloud-*.googledomains.com) is selected—do NOT let the registrar reset nameservers to its default parked DNS, or your live site & email will blip!
8. Avoid the 45-Day GoDaddy Auto-Renewal Clawback Trap Turn Auto-Renew OFF in GoDaddy immediately. Under ICANN/PIR rules, if GoDaddy auto-renews hems-workshop.org first and you transfer out within 45 days after that charge, the .org registry revokes GoDaddy's renewal year unless you manually demand a refund from GoDaddy!
9. Fix Live Email SPF Bug (secureserver.net -all → _spf.google.com ~all) Your live domain uses Google Workspace (MX → smtp.google.com), yet GoDaddy still serves v=spf1 include:secureserver.net -all! That tells .gov/.edu servers to reject Google Workspace mail. Our target zone below fixes this to v=spf1 include:_spf.google.com ~all.
10. Firebase Auth "Authorized Domains" & 15–45 Min SSL Minting Confirm www.hems-workshop.org and hems-workshop.org are in Firebase Auth → Settings → Authorized domains (so Google/Microsoft archive PDF login works immediately). Expect 15–45 minutes after DNS cutover for Firebase's automated SSL padlock to turn green.
