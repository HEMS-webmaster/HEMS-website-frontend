Executive System Overview

The Harsh-Environment Mass Spectrometry (HEMS) Society & Biennial Workshop web platform (hems-workshop.org) is a zero-recurring-cost ($0.00/mo) hybrid static-dynamic scientific platform built on Google Workspace for Nonprofits and the Firebase Hosting Spark Free Tier. Established in 1999 and incorporated as an all-volunteer 501(c)(3) non-profit organization in 2003, HEMS serves both as the active conference hub for the upcoming 16th HEMS Workshop (September 2027) and as the permanent open-access digital archive of 15 historical workshops (1999–2025) encompassing 1,590 proceedings files (1.68 GB).

05 / Research Archives & Static Bundle Optimization

Proceedings Engine, 24.5 MB Lean SSG & Dev Proxy

The archive engine (src/frontend/src/app/archive/[year]/page.tsx) pre-renders static proceedings interfaces for all 15 workshops (generateStaticParams) while keeping the compiled Firebase Hosting static export lightweight.

95% Static Bundle Reduction (508.2 MB → 24.5 MB)

Historical proceedings PDFs previously duplicated under src/frontend/public/assets/archives/ inflated src/frontend/out/ to 508.2 MB. Purging /public/assets/archives (and locking it in src/frontend/.gitignore) shrank out/ to 24.5 MB—enabling sub-minute Firebase Spark deployments and instant preview channels.

Conditional next.config.ts Dual-Mode Routing

In next dev (NODE_ENV !== 'production'), Next.js rewrites /api/manager/:path* to http://localhost:4000/api/manager/:path* so local PDFs stream from local_data/proceedings/. In next build, it switches to output: 'export' and resolves every PDF directly to https://storage.googleapis.com/hems-workshop-archives/....

07 / Upcoming Workshop Control Plane (Replaces Decap CMS)
Active: gid=540431442

$0 Google Sheets CSV + Static JSON Hybrid Engine

Decap CMS was retired in v4.0 because its test-repo mode presented blank editors without existing page context, required GitHub authentication from non-technical academic volunteers, and collided with src/app/(portal)/admin/page.tsx during static builds. In its place, HEMS uses a two-tab Google Sheet hosted inside HEMS's Google Workspace for Nonprofits account coupled with a committed static JSON baseline.

Stage 1 • Frame-0 Static SSG

Every page compiles with DEFAULT_UPCOMING_WORKSHOP imported synchronously from src/data/upcoming_workshop.json. Visitors and search crawlers receive instant HTML with zero loading spinners.

Stage 2 • Live Browser Hydration

useUpcomingWorkshop() fetches the published read-only CSV (cache: 'no-store', Access-Control-Allow-Origin: *) once per session via a deduplicated module-level promise and merges updates via RFC-4180 parseWorkshopSheetCsv().

Stage 3 • Git Snapshot CLI

Running npm --prefix src/frontend run sync:workshop executes scripts/sync-workshop-sheet.js, baking live Google Sheet values permanently into upcoming_workshop.json before major releases.

Google Sheet CSV Sanitization & Firestore Quotas

Published Google Sheets CSV endpoints are strictly read-only, expose only Tab 1 (gid=540431442), and are parsed through parseWorkshopSheetCsv(), which whitelists the 40 typed keys and renders exclusively through React text nodes (preventing XSS injection). Firestore rules in firestore.rules enforce daily download rate limits in downloads_log/{id}.

Hard Repository Locks (.agents/rules/locksrules.md)

  • 🛑 Archive Immutability Lock: src/frontend/src/app/archive/** & data/archives/*.json must never be modified without explicit @bo permission.
  • 🛑 Immutable Reference Lock: /source-material is strictly read-only.
  • 🛑 Memory Firewall: docs/logs/thought_trace.md is strictly append-only (write-only; never read into context).

Authoritative master catalog defining all 15 historical workshops (1999–2025), feeding both /archive/ and the chronological timeline on /history/.

corporate_registry.json src/frontend/src/data/corporate_registry.json

Registry of all 52 historical & continuing corporate sponsors, inception years, external URLs (normalized with https://), and logo filenames under public/images/sponsors/.

11 / Operator & Developer Handbook

Workflows, Staging & CLI Quickstart

1. Run Public Website Locally (Port 3000) 
npm run dev
# Public Website + Live Google Sheet Hydration: http://localhost:3000/
# Portal Admin View (RBAC):                     http://localhost:3000/admin/
2. Snapshot Live Google Sheet Into Git & Run Parity Tests 
npm --prefix src/frontend run sync:workshop
node tests/unit/upcomingWorkshopCsv.test.mjs
# Pulls live CSV (gid=540431442) -> updates upcoming_workshop.json -> verifies 40 keys & 8 surfaces
3. Run Standalone Archive Manager (Port 4000 — Archives & Sponsors Only) 
npm run manager
# Dedicated Proceedings & Sponsor Workbench:    http://localhost:4000/
4. Build Static Export (24.5 MB) & Deploy Private 30-Day Preview Channel ($0) 
gcloud config configurations activate hems
npm run build
npx --prefix src/frontend firebase-tools hosting:channel:deploy preview-2027 --project hems-workshop --expires 30d
# Outputs unlisted https://hems-workshop--preview-2027-<hash>.web.app URL without touching hems-workshop.org
5. Audit Archive Asset Health & Deploy Production 
npm run audit:assets   # Verifies 1,398 proceeding links locally & via GCS HTTP HEAD
git push origin main   # Triggers keyless GitHub Actions WIF deploy to live hems-workshop.org
