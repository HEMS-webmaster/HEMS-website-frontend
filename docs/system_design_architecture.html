Executive System Overview

The Harsh-Environment Mass Spectrometry (HEMS) Society, Inc. platform (hems-workshop.org) is an ultra-low-cost, Always-Free-governed ($0.00/mo steady-state standing compute on Firebase Blaze + Google Workspace for Nonprofits) hybrid static-serverless scientific architecture. Convened first in February 1999 at the University of South Florida (USF) Center for Ocean Technology in St. Petersburg, FL and incorporated in Florida as an all-volunteer 501(c)(3) nonprofit corporation in 2008, HEMS serves both as the operational committee hub for the 16th HEMS Workshop (September 2027) and as the permanent Google-Scholar-indexable digital archive spanning 15 historical workshops (1999–2025) and 1,590 proceedings files (1.68 GB).

07 / Admin Control Center, Auto-Advance & Option 1 Registration
Single Source of Truth: site_config/workshop_live (44 Keys)

Admin Workshop Control Center, Auto-Advance State Machine & 5-Step Registration Fulfillment

1. Zero-Code Control Center + 10m Cache

Replaces legacy Google Sheet CSV ingestion (docs/workshop-sheets/archive/) with /admin/workshop-settings/ (44 keys across 6 plain-English sections). Frame-0 renders upcoming_workshop.json; browser hydrates site_config/workshop_live with a 10-minute sessionStorage TTL cache (or resolves ?preview=<token> Drafts).

2. 4-Phase Auto-Advance Engine

Authoritatively enforced client & server-side (upcomingWorkshop.ts + workshopSchedule.ts reading site_config/workshop_live): transitions before_opening → early_bird → regular → concluded_closed using unified 3-way registration_mode (auto_schedule | open_manual | paused_closed).

3. Atomic 5-Step Registration Fulfillment

Stripe Checkout (card + $5-cap us_bank_account ACH), Invoice/PO, or $0 promo waivers trigger: (1) Sequential HEMS-2027-XXXX receipt #, (2) whitelist attendee role union, (3) Mailing sublist tagging, (4) Abstract cross-link, (5) Postmark IRC § 6115 email + Sheets API v4 append.

08 / Post-Launch Two-Tier Change Control & Staging Workflow
Zero-Risk Board Review

Two-Tier Board Staging: Everyday Config Previews + Full Code Preview Channels

Routine workshop edits (dates, pricing, hotel cutoff, CFP status, venue details) stage cleanly in-browser via Tier A (Control Center Token Previews) with zero programming tools. Structural code/layout edits continue using Tier B (manage-board-preview.ps1) because pushes to origin/main auto-deploy live via GitHub WIF.

Tier A • In-App Config Staging (/admin/workshop-settings)
  • • 1. Save Private Draft: Edits persist to site_config/workshop_draft (strict isAdmin read/write) while visitors see unaffected workshop_live.
  • • 2. Zero-Login Board Link (?preview=<token>): Generates 7–30 day preview URLs backed by site_config_previews/{token}. Reviewers flip [Viewing: Draft | Switch to Live] in PreviewChannelBanner.tsx without logging in.
  • • 3. Visual Diff Publish & <1s Rollback: Side-by-side Before → After table confirms publish via atomic writeBatch into append-only site_config_history/{vNNNN} (allow update, delete: if false), supporting instant 1-click live rollback.
Tier B • Code & Layout Channels (manage-board-preview.ps1)
  • • 1. Draft Branch & Stage: Develop UI/React changes off main; run npm --prefix src/frontend run preview:deploy (or preview:deploy:static-sheet to pin bundled JSON).
  • • 2. Board Sign-Off: Share ephemeral 14-day hems-workshop--board-review-<hash>.web.app URL showing persistent Staging Banner + Compare with Live Page.
  • • 3. Atomic Clone Promotion: Run preview:promote (snapshots pre-promote-backup, promotes in <2s via hosting:clone, supports preview:rollback).

Unified Preview Safety Shield (?preview=* & *--*.web.app)

  • • Search Engine Shield: PreviewChannelBanner.tsx injects <meta name="robots" content="noindex, nofollow" /> into document.head whenever a preview host or token is active.
  • • Analytics Zero-Pollution: Both GoogleAnalyticsTag.tsx (G-F06RZ8L5CR) and telemetryClient.ts (isFirebasePreviewChannelHost() || hasActiveWorkshopPreviewToken()) suppress tracking hits automatically.
  • • Zero Live Footprint: Renders null on hems-workshop.org and localhost during normal traffic.
  • • Static Snapshot Override: Append ?sheet=static or set NEXT_PUBLIC_DISABLE_LIVE_SHEET_SYNC=true to render bundled upcoming_workshop.json.

Shared-Backend Boundary Warning During Preview

  • • Token Draft previews & hosting channels isolate visual presentation cleanly from live visitors.
  • • However, API rewrites (/api/*), Firebase Auth, and live transactional collections share the hems-workshop backend. Avoid submitting real Stripe checkouts or live Postmark broadcasts while browsing a preview URL unless using sandbox test mode.
  • • Changes to firestore.rules or functions/ apply immediately across the project when deployed.

Addendum 36 Hardening Pack Controls

  • • Verified-Identity Role Gate: hasVerifiedAuthEmail() in firestore.rules + isVerifiedDecodedToken() in Functions + isTrustedFirebaseUser() in AuthContext.tsx block unverified email-spoofing escalations (honoring verified emails, Google OAuth, and Microsoft OAuth).
  • • Webmaster Lock & Strict Portal Isolation: webmaster@hems-workshop.org permanently retains admin in UI, useWhitelistAdmin.ts, firestore.rules, and Functions; operations and treasurer do not inherit each other's privileges.
  • • Privacy-Preserving Rate Limiting (rateLimit.ts): Keys IP & email buckets using UTC-daily salted 28-hex SHA-256 digests (zero raw visitor IPs stored) across L1 per-instance memory and L2 Firestore transactions.
  • • Schema & Counter Enforcement: downloads/{doc} enforces downloadCount == 1 on create and +1 on update; mailing_public_requests & telemetry_events bound all field keys and lengths.

Addendum 37 Billing Alert & Auto-Cutoff ($5 Budget → $7.50 Break)

  • • Budget Config: Monthly target $5.00 USD (8e66a672-bc09-401c-bf59-6f5c98bdf1e4) with notifications at 50% Actual ($2.50), 90% Forecasted ($4.50), 100% Actual ($5.00), and 150% Actual ($7.50) → Pub/Sub billing-budget-alerts.
  • • Circuit Breaker Action: Ignores forecast-only alerts; only when actual spend >= $7.50 does budgetCircuitBreaker strip allUsers / allAuthenticatedUsers from gs://hems-workshop-archives, halting runaway egress while keeping hosting, auth, Firestore, and registration 100% online.
  • • Bucket IAM & AR Cleanup: configure-free-tier-guardrails.ps1 keeps 2 gcf-artifacts versions (<500 MB) and binds bucket-scoped roles/storage.admin for the breaker SAs.
